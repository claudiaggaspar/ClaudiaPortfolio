**Goal:** Build a rule-based health classification model using engineered risk factors.  
**Tools:** Python, pandas, scikit-learn, matplotlib.  

**Key insights:**
- Created target variable based on BMI, blood pressure, cholesterol, glucose, and lifestyle metrics.  
- Trained Decision Tree and Random Forest models.  
- Explored numeric variable distributions and correlations.

**Performance:**  
ROC-AUC ≈ 0.51, showing limited predictability — dataset likely too balanced or random.
